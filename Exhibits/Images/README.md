# Exhibit Images

Validation executables under `Exhibits/` render their deterministic `.png` visual exhibits into the domain folders here
(`Exhibits/Images/<Domain>/`).

The rendered images (about 242 MB) are kept on the `SultanAladin/Frontier` repository branch
`arena/4c9015d5-frontier` and are not duplicated into this repository; run the CTest suite to regenerate them locally.
The empty `.gitkeep` entries keep each domain folder present for validations that write without creating directories.
