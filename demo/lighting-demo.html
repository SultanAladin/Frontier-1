Scene: SDF raymarched ground + car body (rounded box) + spheres. Same light list drives PBR, Matcap and SDF modes — only the BRDF / normal source changes. Clustered culls lights in JS to the camera neighbourhood (nearest 32) + radius reject in shader. Brute evaluates every light per pixel. ReSTIR-sim evaluates 1 random light per pixel per frame (unbiased, noisy) — watch the noise. That noise is why ReSTIR is Phase 2, not Phase 1.

🎛 Controls

Light types in shader: Point (analytic), Spot+IES (texture-profile function), Rect (LTC approx: solid-angle × N·L, GGX to centre). Env = procedural PMREM-style studio (softbox stripes), 1 sample.

🗺 Cluster heatmap (world XZ grid)

Lights per 4×4 world cell. Clustered mode only evaluates lights near the camera — empty cells cost ~0. Brute pays for all of them.

🔦 IES polar plot (same function as shader)

Candela vs angle from beam axis. Headlight = narrow beam + horizontal cutoff. This is the exact iesProfile() the fragment shader calls.

Verdict for AutoSpace: Ship Forward+ Clustered for Point/Spot, separate capped LTC list for Rect softboxes, IES texture on headlight Spots, PMREM env always on, pooled shadow maps (top-N importance). SDF reuses the same core (normal = ∇SDF). ReSTIR DI plugs in later as a sampler — it does not replace any of the above.
