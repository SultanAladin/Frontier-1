BUILD

Runs entirely in your browser: the cluster DAG is built in a worker, selection runs on the CPU each frame, and WebGL2 rasterises the selected clusters. Error values are quadric RMS estimates, not certified bounds. No occlusion culling, streaming or software rasteriser.
